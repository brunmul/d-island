# Créer le projet claude.ai « Atoll »

1. Sur claude.ai : Projets → Nouveau projet → nom « Atoll ».
2. **Instructions du projet** : coller le contenu de `instructions.md` (sans le titre).
3. **Connaissances** : glisser ces fichiers du dépôt :
   - `docs/claude-project/etat-du-projet.md`
   - `docs/custom-roadmap.md`
   - `CLAUDE.md`
   - `Branding.cs`
   - `Services/IslandTheme.cs` (le modèle de thème et les presets)
   - `PRIVACY.txt`
4. Mettre à jour `etat-du-projet.md` et la roadmap après chaque étape importante, et re-glisser les fichiers (les connaissances d'un projet ne suivent pas le dépôt).
